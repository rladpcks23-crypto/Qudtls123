# NEON MILE

GTA 스타일의 3인칭 오픈월드 액션 게임. 브라우저에서 바로 실행되며, 빌드 과정도
외부 에셋(모델·텍스처·오디오 파일)도 없습니다. three.js 하나만 CDN에서 불러옵니다.

## 실행

```bash
cd game
python3 -m http.server 8080      # 또는 npx http-server -p 8080
# http://localhost:8080 접속
```

ES 모듈을 쓰기 때문에 `file://` 로 직접 열면 동작하지 않습니다. 반드시 HTTP로 서빙하세요.

## 조작

| 키 | 동작 | | 키 | 동작 |
|---|---|---|---|---|
| `WASD` | 이동 / 운전 | | `F` | 차량 탑승·하차 |
| `Shift` | 달리기 | | `1` `2` `3` | 주먹 / 권총 / SMG |
| `Space` | 점프 · 핸드브레이크 | | `R` | 재장전 |
| 마우스 | 시점 | | `E` | 경적 |
| 좌클릭 | 발사 | | `Esc` | 일시정지 |
| 우클릭 | 조준 (어깨 너머 시점) | | | |

모바일에서는 좌측 가상 스틱 + 우측 버튼, 화면 드래그로 시점을 조작합니다.

## 게임 내용

- **오픈월드** — 8×8 블록(640m×640m)의 항구 도시가 고정 시드로 절차적 생성됩니다.
  다운타운일수록 건물이 높아지고, 공원·주차장·네온 간판·가로등·신호등이 배치됩니다.
- **교통 시뮬레이션** — NPC 차량이 우측통행 차선을 따라 주행하고 교차로에서 진로를
  선택하며, 앞차와 보행자를 감지해 감속합니다. 보행자는 인도를 순회하다 총성이나
  질주하는 차를 보면 도망칩니다.
- **차량** — 세단·스포츠카·SUV·밴·택시·순찰차. 아케이드 물리(구동력, 그립, 드리프트,
  핸드브레이크), 차량 손상과 폭발, 타이어 연기, 브레이크등·헤드라이트.
- **수배 시스템** — 1~5★. 범죄를 저지르면 별이 오르고 순찰차와 도보 경관이 추격합니다.
  시야에서 벗어나면 서서히 수배가 해제됩니다.
- **돈벌이** — 파란 마커(일감 게시판)에서 계약 3건 중 하나를 고릅니다. 배달·승객 운송은
  **합법**이라 수배가 붙지 않고, 차량 탈취·계약 타격은 수배가 올라갑니다.
  택시를 타고 `T`를 누르면 **택시 영업**이 시작되어 승객을 태우고 내려줄 때마다
  거리 비례 요금(+신속 보너스)을 무제한으로 벌 수 있습니다 — 완전 합법.
- **상점** — 미니맵에 항상 표시되는 3곳.
  - 🔴 **무기상** SMG $2,200 · 탄약 · 방탄복 $600
  - 🔵 **차량 대리점** 세단 $3,500 ~ 스포츠카 $16,000 (구매한 차는 매장 앞에 인도되고
    사라지지 않습니다, 최대 3대)
  - 🟢 **편의점** 체력 회복
  시작 시에는 권총 30발만 가지고 있고, SMG는 구매해야 사용할 수 있습니다.
- **낮·밤 사이클과 날씨** — 5분 주기의 낮밤 변화, 밤에는 창문·네온·가로등 불빛이 켜지고
  비가 오면 노면이 젖어 빛을 반사합니다.

## 그래픽

- PBR 머티리얼 + ACES 필름 톤매핑 + UnrealBloom
- 하늘 그라디언트·태양·별을 그리는 커스텀 셰이더, 그 하늘로 만든 PMREM 환경맵을
  차체·유리·수면 반사에 사용
- 플레이어를 따라다니는 캐스케이드형 그림자 카메라 (PCFSoft)
- 모든 텍스처는 로드 시점에 캔버스로 그려서 생성 (파사드/창문 조명, 아스팔트, 콘크리트, 잔디)
- 정적 지오메트리는 머티리얼별로 병합되어 도시 전체가 10여 개의 드로우콜로 그려집니다
- 품질 3단계(낮음/중간/높음)로 그림자 해상도·블룸·픽셀비·교통량을 조절

## 사운드

효과음 파일 없이 WebAudio로 합성합니다. RPM을 따라가는 엔진음, 사이렌, 총성,
충돌음, 스키드, 발소리에 짧은 컨볼루션 리버브를 걸었습니다.

## 코드 구조

```
game/
├── index.html      HUD·메뉴 마크업과 스타일, import map
└── src/
    ├── main.js       게임 루프, 플레이어 컨트롤, 카메라, 수배/스트리밍, 낮밤
    ├── city.js       도시 절차 생성, 충돌용 공간 해시, 야간 조명
    ├── vehicle.js    차량 모델·물리·교통/경찰 AI
    ├── character.js  로우폴리 인간형 + 절차적 애니메이션
    ├── npc.js        보행자·도보 경관
    ├── missions.js   일감 게시판과 계약 진행
    ├── shop.js       상점 카탈로그와 구매 오버레이
    ├── fx.js         파티클·트레이서·목표 마커
    ├── hud.js        HUD와 회전 미니맵
    ├── textures.js   캔버스 절차 텍스처
    ├── audio.js      WebAudio 합성 사운드
    ├── input.js      키보드·마우스·터치
    └── util.js       수학·난수 유틸
```
