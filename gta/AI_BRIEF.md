# 네온 하버 (Neon Harbor) — 다른 AI에게 의견을 구하기 위한 프로젝트 요약

> 이 문서만 읽어도 게임이 무엇이고, 무엇이 이미 있고, 앞으로 무엇을 하려는지 알 수 있게 쓴 요약이다.
> 코드를 직접 고칠 AI는 저장소 최상위의 `knowledge.md`(파일 구조·수정 요령)도 함께 읽는다.
> 버전: **v2.17** (2026-09) · 저장소 `gta/` 폴더 · 브랜치 `claude/gta-style-game-dev-j6qp50`

## 1. 한 줄 요약

GTA 1·2처럼 위에서 내려다보는 **오픈월드 범죄 액션 게임**이다. 1인칭·3인칭 3D 시점(Three.js)도 된다.
**PC 전용**이고 순수 JavaScript로 만든 **HTML 파일 하나**다. 윈도우 설치 파일(.exe)도 있다.
화면 글·대사·주석은 모두 **한국어**다.

- 실행: `gta/build/neon-harbor-pc.html`을 브라우저로 열거나 `gta/release/NeonHarbor-Setup.exe`를 설치한다
- 빌드: `cd gta && python3 build.py` (`src/*.js` 25개를 순서대로 이어 붙여 파일 하나로 만든다. 번들러·npm 의존성 없음)
- 크기: 소스 약 12,700줄, 빌드 결과 약 1.5MB (Three.js 포함)

## 4. 지금 있는 기능

### 액션
- **무기 15종**: 권총·기관단총·샷건·저격총·로켓·수류탄 등
- **차량 물리와 AI**
  - 자전거 모델 물리, 교통 AI(IDM), 신호등, 무단횡단 규칙
  - 차 파손: 찌그러짐, 연기, 펑크, 깨진 헤드라이트
- **탈것**: 오토바이, 보트, 헬기, 전투기, 전차, 여객기, 낙하산
- **경찰**
  - 수배 1~5성, 순찰차·헬기
  - 바리케이드와 스파이크 띠, 밤에는 서치라이트
  - ★5가 오래가면 현상금 사냥꾼
- **스턴트 점프 14곳**(슬로모션), **레이스**(거리 3곳, 보트, 헬기 링)
- **날씨**(맑음·비·안개·폭풍), 낮과 밤, 건물·차량 화재
- **랜덤 이벤트 6종**: 날치기, 현금 수송차, 거래 현장, 교통사고, 도주 차량, 화재

### 스토리·일
- **스토리 미션 26개**
  - 1장 14개와 2장 12개
  - 컷신이 있고, 25장에서 '윤'과 '한' 두 갈래로 나뉜다
  - 엔딩 크레딧이 있다
- **직업 10가지**: 택시, 구급대원, 음식 배달, 버스, 자경단, 소방관, 차량 수출, 밀수, 현금수송차 습격, 소매치기
- **의뢰인 NPC와 동네 대화**

### 조직 (갱)
- **4대 조직과 새 조직 '검은 연꽃'**
  - 도시 블록 단위로 구역을 나눠 갖는다
- **내 조직 만들기**
  - 조직원 수, 부하 호출·호위, 조직 관리(O)
- **구역 넓히기**
  - 지도에서 블록을 골라 습격한다
  - 부하를 한꺼번에 파견할 수 있다
- **전면전**: 조직 전체 대 전체. 전선이 옮겨 가다 한쪽이 궤멸하고, 궤멸한 조직은 재건한다
- **적 위치 표시**: 머리 위 역삼각형, 화면 가장자리 화살표, 레이더

### 돈 콘텐츠 (사용자가 가장 좋아하는 부분)
- **사업체 32곳**: 1~5단계 업그레이드, 1분마다 수입, 건물 위에 단계와 수입 표시
- **사업 이벤트**: 파업, 세무조사, 보호비 요구 같은 선택지 사건
- **부동산 임대 22곳**
  - $6만 단독주택부터 $2억 5천만 네온 스카이 타워까지
  - 임대 수입은 1분마다 들어오고, 최고가 건물은 1분 $221만이다
- **하버 개발**: 빈 필지에 아파트·오피스·초고층을 지으면 실제 건물이 올라간다
- **주식, 인수합병**
  - 지분 51%면 경영권과 배당을 얻는다
  - 라이벌 강 회장과 적대적 인수전을 벌인다
- **중앙은행**: 예금 이자 1분 3%, 대출 이자 1분 4%
  - 대출이 예금보다 높아야 빌려서 맡기는 돈 복사가 막힌다
- **창고 무역과 밀수**, **대형 강도**(준비 작업 후 본 작전)
- **국회 법안**: 사업세 인하, 임대료 상한 폐지 등
- **후원**: 병원·경찰에 돈을 내면 지지도가 오르고 혜택이 생긴다
- **시장 선거**: 당선되면 시장 혜택을 받는다
- **대저택**: 금고 털이 습격을 막아야 하고, 명품 수집 컬렉션이 있다
- **카지노**: 룰렛·슬롯·블랙잭, VIP 한도 $5M
- **학교 경영 강의**: 모든 수입 최대 +25%

## 7. 기술 구조 (코드를 볼 AI용)

- `gta/src/*.js`를 `build.py`의 `ORDER` 순서대로 이어 붙인다. **전역 스코프를 공유한다** (import 없음)
  - `core` → `world` → `county` → `vehicles` → `peds` → `police` → `missions` → `jobs` → `npc`
  - → `military` → `render` → `view3d` → `ui` → `economy` → `gangs` → `empire` → `finance`
  - → `wardrobe` → `casino` → `events` → `stunts` → `life` → `story` → `tycoon` → `main`
- 맵 생성
  - `genWorld(seed)`는 `genCity`(도시 640×640, 예전과 동일) → `widenWorld(1400,640)` → `genCounty` 순서로 돈다
  - 도시 기준 좌표가 필요하면 `CITY_W`/`CITY_H`를 쓴다. `MW`/`MH`는 전체 맵이다
- 타일 `TL`
  - 종류: WATER, ROAD, WALK, BUILD, GRASS, SAND, LOT, PLAZA, DOCK, RUNWAY, **ROCK(산)**
  - 산 높이는 `World.rockH`, 3D 지형은 `mountainH(tx,ty)`
- 도로
  - 노드·간선 그래프는 `World.nodes`/`edgesList`, 축 방향 직선만 쓴다
  - `roadK`: 1 세로, 2 가로, 3 교차로, 4 대로, 5 골목, 6/7 고속도로 바깥 차선
  - 카운티 4차선은 `World.hwEdges`
- 장소 추가
  - 걸어 들어가는 문 마커: `World.places[key]`
  - 상점 연결: `EXTRA_PLACES.push([key, shopKey])`
  - 지도 아이콘: `EXTRA_ICONS`
  - 문 앞 고리 색: `PLACE_MARK`
  - 상점 내용: `SHOPS[shopKey]`
- 새 기능 저장: `SaveExt.mods.이름 = { save(), load(o) }`
- 공용 소품(2D·3D 동시): `Props.providers`
- 목표 표시(GPS·화살표): `allTargets()`
