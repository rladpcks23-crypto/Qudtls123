# 수능 기도회 찬양 추천판

선교부 사람들이 수능 기도회에 쓸 CCM을 추천하고, **누가 어떤 곡을 추천했는지** 한눈에 보는 페이지입니다.

- **곡별**: 같은 곡은 하나로 묶고 "N명 추천"과 추천한 사람, 추천 이유를 함께 보여 줍니다.
- **추천인별**: 사람마다 추천한 곡 목록을 보여 줍니다.
- **확정 콘티**: "콘티에 넣기"를 누른 곡을 기도회 순서(①여는 찬양 ②경배 ③기도 ④위로·축복 ⑤마무리)대로 정리합니다. 카톡에 붙여 넣을 텍스트도 복사할 수 있습니다.
- 유튜브 링크는 "유튜브에서 듣기" 버튼으로 바로 열립니다. 링크가 없으면 제목과 가수로 유튜브 검색 버튼이 생깁니다. 멜론 같은 다른 링크도 넣을 수 있습니다.
- 2027학년도 수능(2026-11-19) D-day를 보여 줍니다.

## 쓰는 방법 1: claude.ai 링크 (설치 필요 없음)

claude.ai 아티팩트로 올려 두었습니다. 추천은 아티팩트의 공유 저장소에 쌓입니다.
같이 쓰는 사람도 claude.ai에 로그인해야 하고, 공유 메뉴에서 **편집 권한**을 받아야 추천을 올릴 수 있습니다(보기 권한만 있으면 목록만 보입니다).

## 쓰는 방법 2: 직접 서버 띄우기 (계정 없이 누구나)

Node.js 18 이상만 있으면 됩니다. 설치할 패키지는 없습니다.

```bash
cd ccm
node server.js            # http://localhost:3000
PORT=8080 node server.js  # 포트 바꾸기
```

- 추천 목록은 `ccm/data/songs.json`에 저장됩니다(`DATA_DIR`로 위치를 바꿀 수 있습니다).
- 같은 와이파이에 있는 친구들은 `http://<내 컴퓨터 IP>:3000`으로 들어올 수 있습니다.
- 인터넷에 올리려면 Render, Railway 같은 Node 호스팅에 `ccm` 폴더를 올리고 시작 명령을 `node server.js`로 정하면 됩니다. 무료 플랜은 재시작할 때 파일이 지워질 수 있으니, 디스크(Persistent Disk)를 붙이고 `DATA_DIR`을 그 경로로 설정하세요.
- 로그인 기능이 없어서 주소를 아는 사람은 누구나 추천을 올리고 지울 수 있습니다. 화면에서는 자기 브라우저에서 올린 추천만 지울 수 있게 해 두었습니다. 주소는 선교부 단톡방 안에서만 공유하세요.

## 파일

| 파일 | 내용 |
| --- | --- |
| `index.html` | 화면 전체. claude.ai 아티팩트, 직접 띄운 서버, 그냥 파일로 열기 세 경우를 알아서 구분합니다(파일로 열면 그 브라우저에만 저장). |
| `server.js` | 의존성 없는 Node 서버. `GET/POST /api/songs`, `PATCH/DELETE /api/songs/:id` |
